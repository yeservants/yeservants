PROJECT BRIEF
─────────────────────────────────────────────
Name:              Yielded Evangelical Servants (Y.E.S.)
Type:              Marketing / Nonprofit Site — Real client site
Purpose:           Connect donors, church partners, and potential
                   missionaries to a global evangelical mission.
                   Inspire generosity and service.
Aesthetic Tone:    Warm Editorial Dignity — premium faith magazine
                   aesthetic. Handmade-paper warmth, generous
                   whitespace, editorial serif authority.
The Unforgettable: The missionaries listing page reveals each portrait
                   via a diagonal clip-path wipe animation as the user
                   scrolls — faces being uncovered from a curtain.
                   Oversized ghost location names in 10-16vw bleed
                   behind each portrait row as atmospheric typography.
Heading Font:      Fraunces (warm editorial serif, optical sizes)
Body Font:         General Sans (clean, readable, contrasting genre)

Color Palette:
  --bg:            #FAF8F4   (Warm off-white, aged paper)
  --surface:       #F0EBE3   (Cards / elevated areas)
  --primary:       #2C4A3E   (Deep forest green)
  --accent:        #C27D41   (Warm amber)
  --text:          #1C1C1A
  --text-muted:    #6B6560
  --border:        rgba(44,74,62,0.12)

Signature Element: Diagonal clip-path portrait reveals on missionaries
                   page + ghost location typography behind each row.
Background Style:  Grain overlay on hero + subtle dot grid on content
                   sections + atmospheric radial glows in forest green/
                   amber at 3-5% opacity.

Hero Pattern:      H5 Statement Typography — massive Fraunces italic
                   heading at 9-13vw. The font IS the design.
Hero Scroll Effect: GSAP ScrollTrigger scrub drives hero text opacity
                   from 1 to 0 and slight scale from 1 to 0.95 as the
                   user scrolls past. Hero dissolves into first section.

Pages:
  1. /              — Home (H5 hero)
  2. /missionaries/ — Editorial grid with clip-path reveals
  3. /missionary/[slug]/ — Portrait detail + bio + donate CTA
  4. /donate/       — Donation page (Aplos link + mail-in)
  5. /join/         — Get Involved page (with image carousel)
  6. /contact/      — Contact info (both emails, address, phone)
  7. /privacy/      — Privacy policy page
  8. /thanks/       — Thank you confirmation page

Runtime:           Node.js + npm
Styling:           Tailwind CSS v4
